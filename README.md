# Astrological Solutions — Premium 3D Demo

A premium, conversion-focused astrology commerce + consultation demo built for Astrological Solutions by Waterting Solutions.

## Included
- Cinematic entry loader
- Three.js interactive 3D hero
- Consultation-first conversion funnel
- Expert profile cards and availability UI
- Product catalogue with real-stock imagery
- Prepaid offer and checkout demo
- Responsive mobile-first layout
- SEO-ready HTML foundation

## Run locally
Open `index.html` directly, or serve the folder with any static server.
